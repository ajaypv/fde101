Use these definitions to make a design discussion clearer. Each term should answer “what does it do here?” rather than advertise a product.

## A–C

**Agent**  
A model-driven loop that can choose actions or tools while pursuing an objective. It needs explicit limits, observable state, and safe side-effect handling.

**Chunk**  
A retrievable unit created from a larger source document. Good chunks preserve enough local meaning and source metadata to answer and cite.

**Context window**  
The maximum token budget a model can consider in one call, including instructions, user input, retrieved evidence, tool results, and output allowance.

## E–L

**Embedding**  
A numeric representation used to compare semantic similarity. [Read the full entry.](/glossary/embedding/)

**Evaluation, or eval**  
A repeatable case, expected behavior, scoring method, and decision rule used to measure a system.

**Groundedness**  
The degree to which an answer’s claims are supported by the evidence made available to the model.

**Hallucination**  
A generated claim that is not supported by available evidence. [Read the full entry.](/glossary/hallucination/)

**LLM**  
A large language model that generates tokens from the context supplied to it.

## P–T

**Precision@k**  
Relevant items in the top `k` results divided by the number of returned items considered.

**Recall@k**  
Relevant items found in the top `k` results divided by all known relevant items.

**RAG**  
Retrieval-augmented generation: retrieve external evidence, place it in model context, then generate a grounded answer. [Read the full entry.](/glossary/retrieval-augmented-generation/)

**Reranker**  
A second scoring stage that reorders candidate results, often using a more expensive but more precise model.

**Token**  
A unit of text processed or generated by a language model. A token is not always a full word.

**Tool**  
A function or external capability a model-driven workflow can request, such as search, database lookup, or ticket creation.

**Vector store**  
A system that stores vectors and returns nearby items according to a similarity function, usually with metadata filters.
